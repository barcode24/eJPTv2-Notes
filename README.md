# eJPTv2-Notes
eJPTv2 Essentials: Notes & Cheatsheet for the exam, with commands and tools shown in the course.

> My comprehensive study notes, methodology walkthroughs, and practical labs summary for the **eJPTv2 (eLearnSecurity Junior Penetration Tester)** certification.

---

## 📌 About This Repository
This repository documents my hands-on learning journey and practical application of penetration testing concepts. It serves as a quick-reference cheat sheet and a proof-of-skills portfolio showcasing foundational offensive security capabilities.

---

## 🛠️ Core Modules & Topics Covered
- **Information Gathering & Reconnaissance:** Network scanning (Nmap), enumeration, and OSINT.
- **Host & Network Penetration Testing:** Exploitation fundamentals, Metasploit framework, and pivoting.
- **Web Application Security:** HTTP basics, OWASP Top 10 vulnerabilities, and manual testing techniques.
- **Post-Exploitation:** Maintaining access, privilege escalation basics, and pivoting.
